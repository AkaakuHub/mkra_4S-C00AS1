# EPGStationの通常BS番組表・録画

役割を分ける。mkraは選局・TS・CAS・単一チューナーの排他を担当し、別LinuxサーバのEPGプロキシは通常BSのH-EITと4K番組表cacheを統合する。EPGStationの既存UI・予約DB・録画機構を利用する。

詳細な配置は[tools/epgstation/README.ja.md](../tools/epgstation/README.ja.md)。ネットワーク4と11は番組ID・サービスIDで区別する。BS4K→BSの種別表示変換でIDまで同一にしてはならない。

## 継続課題

- 単一チューナーなのでEPG巡回も受信を占有する。共通flock、録画前の延期、中断チェックを使うが即時録画との競合を完全には防げない。
- 番組延長・時刻変更へのリアルタイム追従は未完成。cacheの取得周期とEPGStationの更新周期に依存する。
- 2.10.0向け待機時間・10bit再生修正は特定の設定を前提とし、他版へ無条件適用できない。
- 予約・録画DBや私的設定は配布しない。既存環境をバックアップし、録画のない時間に導入する。
