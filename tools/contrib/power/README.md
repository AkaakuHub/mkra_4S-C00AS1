# AS1の電源設定ツール

このブランチには純正ソフトのRAM上の電源設定を扱うツールが含まれています。本体のfreeze待機とMagic Packet起床を実装するカーネルモジュールは含まれていません。

`keep_awake.pl`は純正`abs`のハッシュと設定値を照合し、クイック起動と無操作オフの設定を確認・変更します。スクリプトは本体の永続ストレージへ書き込みません。既存の管理手段でRAMへ転送し、純正のPerlで実行します。

```sh
/usr/bin/perl /tmp/mt/keep-awake.pl
```

純正サービスの稼働と、対象ファームウェアの一致が必要です。これだけでは本体の停止や通信断から復帰できません。
